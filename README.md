# Internship Finder System

## 📌 Project Description
Internship Finder System is a web-based application developed to help students find internship opportunities easily and allow companies to post internship vacancies in one platform.

This system is mainly built for students who are seeking internships and companies who want to hire interns efficiently.

---

## 🎯 Features

### 👨‍🎓 Student Side
- Student registration and login
- View available internship opportunities
- Search internships by category
- Apply for internships
- View applied internships

### 🏢 Company Side
- Company registration and login
- Post internship vacancies
- View student applications

### 🔐 Authentication
- Secure login system
- Role-based access (Student / Company)
